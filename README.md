# Tech Radar

A personal technology radar and architecture decision log for Java, Spring, data, caching and messaging.

- **Tech Radar:** technologies placed in Adopt, Trial, Assess or Hold, with the reasoning for each.
- **Decisions:** Architecture Decision Records (context, options, decision, consequences).

## Editing

All content is in [`data.js`](data.js). Edit it, commit, and push; GitHub Pages republishes automatically.
Set `draftNotice: false` in `data.js` once the content has been reviewed.

## Running locally

Open `index.html` through any static web server, for example:

```bash
npx http-server .
```

No build step; plain HTML, CSS and JavaScript.
